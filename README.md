## Main Project: Ki-kernel

Custom Android kernel, still actively updated.

| Device | Codename | Kernel |
|--------|----------|--------|
| POCO F4 / Redmi K40S | munch | Linux 4.19 |
| POCO X3 Pro | vayu / bhima | Linux 4.14 |

What's inside:
- KernelSU + SuSFS support
- Ki-Profile: switch between Battery, Balanced and Performance
- Bypass charging and fast charge controls
- BBRv3 network congestion control
- Droidspaces / LXC / Docker support
- Works on MIUI/HyperOS, AOSP, and ColorOS/OxygenOS (munch)

Download: [latest release](https://github.com/Luckyfr1945/ki-kernel/releases/latest)  
Updates and bug reports: [Telegram channel](https://t.me/+i7NfuXZA6mZjOWJl)

> [!WARNING]
> Flash at your own risk. Always back up your boot image first.
